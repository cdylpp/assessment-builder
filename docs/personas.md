# Personas

## Admin (Owner)

A user who creates, modifies, manages, and administers assessments.

### Modules

1. Assessment builder.
2. Assessment proctor.
3. Guest management.
4. Results viewer.

#### Assessment builder

This module allows the owner to create, edit, delete, and view built assessments. Actions within this module are:

- CRUD on Events, Competencies, Methods, Variables
- Docs for building such items.
- Versioning for Assessments.

## Participant (Guest)

Participant: user who is scored by the assessments.
Provided limited guest access so a small set of surveys. Can view their own scores and that's it.
Can review comments, outcomes of events they were in.
